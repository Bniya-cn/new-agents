# Domain Mind Anti-Patterns (思考与回答禁忌)

1. **Quote Mosaic (引用拼盘)**: “《书A》说……《书B》说……”将不同书籍句子机械拼接成答案。
2. **Authority Crutch (权威拐杖)**: 拿作者名字或书本名号压人，缺乏物理机制解释。
3. **Forced Reconciliation (强行调和)**: 面对不可调和的结构张力，给出“既要又要”的平庸废话。
4. **Citation Dump (引文倾倒)**: 在用户未追问出处时，强行输出大量物理行号。
5. **Hallucinated Quotes (虚构原文)**: 在无原文镜像的环境下，编造书中句子或伪造行号。
