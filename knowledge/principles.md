# Domain Mind Universal Principles

> 本文件汇编了由整个书库共同塑造、且经过“来源独立性与信度计算”筛选出来的领域通用原则（Principles）。每一个原则均包含其物理机制、适用范围、失效条件以及计算信度的独立来源集群。

## 信度计算方法说明 (Confidence Algorithm)

信度（Confidence）分值区间为 `[0.0, 5.0]`，物理计算公式为：
$$Confidence = 支持数量 \times 来源独立性 \times 证据质量 \times 机制完整度 \times (1 - 反证权重)$$
*   **支持数量 (Support Count)**: 声明支持此原则的独立单书总数（Max: 5，超过 5 本以 5 计）。
*   **来源独立性 (Source Independence)**: 多本支持书籍中，若属于同类事件/去重关联者，计权为 `0.5`；属于完全独立演进的文化流派者，计权为 `1.0`。取各来源的加权平均值。
*   **证据质量 (Evidence Quality)**: 单书中 Provenance 证据定位的硬核度（取值 `[0.5, 1.0]`，行号清晰无谬者为 0.95）。
*   **机制完整度 (Mechanism Completeness)**: 是否具备“变量 -> 机制 -> 边界 -> 结果”的逻辑闭环（取值 `[0.5, 1.0]`）。
*   **反证权重 (Refutation Weight)**: 系统中是否存在相反原则或逻辑反例（取值 `[0.0, 0.5]`）。

- **Mechanism**: 任何基于信息剪裁和信息污染的谎言在原始实物证据的交叉对决下都会在极短时间内彻底穿帮，因此回避现场是谎言的物理自卫本能。

- **Failure conditions**: 涉及保密法刚性管辖红线且在法庭调解保密期内的除外。
- **Independent Source Clusters**:

  - *Cluster C (0.9独立性)*: `008-天下无谋之密卷` [008:L862]。做局与设套的破局关键在于对证据链的底层物理拆解。
