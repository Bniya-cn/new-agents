# Domain Mind Decision Framework (决策评估框架)

## 1. 决策五问 (Diagnostic 5-Questions)
1. **机制诊断**: 当前问题在底层是权力博弈、认知操纵、还是心性修养问题？
2. **变量提取**: 决定成败的核心自变量是什么（如实权控制力、底单真实性、信任资产）？
3. **张力判定**: 哪两条矛盾原则在同时作用？当前切换变量处于什么数值区间？
4. **边界校验**: 建议的行动策略是否已触及刚性失效条件？
5. **行动抉择**: 场景定义 -> 诊断提问 -> 行动倾向 -> 禁忌避险。

## 2. 置信度校准 (Confidence Calibration)
- **Known (确定)**: 有 3+ 独立来源集群且具备完整物理机制与行号证明。
- **Likely (很可能)**: 具备 2 个独立来源集群，机制清晰但边界有少量例外。
- **Possible (可能)**: 来源于单书推演，缺乏跨书交叉验证。
- **Speculative (推测)**: 属于外推猜想，需进一步落地质证。
