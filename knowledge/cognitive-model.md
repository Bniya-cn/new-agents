# Domain Mind Synthesized Cognitive Model

> 本文件是领域认知系统的核心知识库。它融合了 19 本 Canonical 书籍的底层认知模型，归纳出核心概念本体（Ontology Concepts）、跨书因果模型（Causal Models）以及流派间的核心张力（Tensions）。

---

## 1. 核心概念本体 (Ontology Concepts)

### C001 认知失调与自我辩护 (Dissonance & Self-justification)
*   **Definition**: 当个体的行为与其高尚的自我概念（“我是个好人/聪明人”）发生逻辑冲突时，大脑会产生强烈的生理性紧张感（失调）。为了消除不适，大脑会在无意识中修改信念、扭曲对物理事实的记忆，以合理化自身的错误决定。
*   **Role**: 诱导受害者自发维护骗子项目的内生心理引擎。
*   **Provenance**: `[017:L1548]`, `[012:L4256]`, `[021:L46]`

### C002 瑕疵串联假证据链 (Fake Evidence Chain)
*   **Definition**: 构陷者从庞大的真迹事实中裁剪并挑出极少数（如 1%）偶发性的偶发瑕疵（如错别字、笔迹微差），通过臆测将这些不相干的小瑕疵强行串联在一起，强行虚构出“处处反常、必是伪造”的强质疑证据链，以击中人类偏爱关注反常的心理。
*   **Role**: 瓦解系统社会信誉的舆论战武器。
*   **Provenance**: `[011:L633]`, `[011:L1137]`, `[019:L200]`

### C003 去人性化污名化 (Dehumanization)
*   **Definition**: 施暴者或构陷者在心理和修辞上剥夺攻击目标的“人的属性”，给其贴上“方黑”、“老鼠”、“利益集团的走狗”等宏大恶意标签。
*   **Role**: 屏蔽自身的道德内疚，为下一次加码伤害扫清心智障碍。
*   **Provenance**: `[017:L2170]`, `[019:L1356]`

### C004 雄猜之主与特务控制 (Autocratic Terror)
*   **Definition**: 专制决策者因为极度缺乏安全感，对臣下和知识分子心存疑忌，废除制度制衡，设立法外特务组织进行秘密监视，并大兴文字狱大清洗以制造绝对的恐惧服从。
*   **Role**: 独裁权力的防御性清洗本能。
*   **Provenance**: `[001:L104]`, `[001:L1792]`, `[019:L721]`

### C005 御下隔离与维持底细神秘 (Emotional Detachment)
*   **Definition**: 管理者坚决不在非正式场合向部属透露个人的情感好恶、经济底细或私人弱点，通过森严的职业礼仪与下属拉开物理与心理距离，防止被部属针对性迎合与反向操纵。
*   **Role**: 组织控制的核心防御机制。
*   **Provenance**: `[019:L307]`, `[008:L862]`, `[013:L124]`

### C006 心即理与作为人何谓正确 (Moral Realism)
*   **Definition**: 天理不在心外的物理客体上，而是吾心良知本体在具体人伦事务上的得宜发用。将人类最朴素的童蒙常识（诚实、守信、不贪、不害人）作为指导商业和人生一切决策的最高风控门禁。
*   **Role**: 商业与人生抉择的最优去伪算法。
*   **Provenance**: `[003:L196]`, `[016:L68]`, `[010:L2416]`

### C007 必有事焉的日常省察 (Daily Self-reflection)
*   **Definition**: 终身将“致良知”作为唯一一件要紧事，无论有事无事、在工作岗位（事上磨炼）和日常得失毁誉中，始终保持“心体常惺惺”的警醒反省状态。
*   **Role**: 阻断私欲悄然滋生的日常修行机制。
*   **Provenance**: `[003:L3106]`, `[003:L3322]`, `[016:L76]`

## 2. 跨书因果模型 (Causal Models)

### CM001 极化自毁环（行为绑定 -> 认知失调 -> 自我辩护 -> 污名受害者 -> 伤害加码）
- **Mechanism**:
  个体在从众压力或利欲驱使下做出了伤害他人或高风险入局的不可挽回动作（行为绑定）
  → 其行为与“我是好人/聪明人”的自我概念发生冲突，产生生理焦躁（认知失调）
  → 不愿承认愚蠢而疯狂寻找借口合理化行为（自我辩护）
  → 在心理上将受害者/揭发者贴上敌对去人性化标签（污名化）
  → 彻底屏蔽道德内疚，对受害者进行下一次更大规模的加码伤害
  → 态度极化为狂热伥鬼。
- **Conditions**: 前期付出的金钱或声誉沉沉成本极大。
- **Provenance**: `[017:L1548]`, `[012:L4256]`, `[019:L2170]`, `[021:L46]`

```
[行为绑定 (入局/伤害)] ──> [产生强烈认知失调] ──> [启动自我辩护]
       ^                                                │
       │                                                v
[进行下一次更大伤害] <── [污名化目标 (去人性化)] <── [扭曲客观事实]
```

### CM002 变革自毁环（偏执强推新政 -> 排除理性异议 -> 起用谄媚帮凶 -> 执行变形盘剥 -> 组织大崩盘）
- **Mechanism**:
  变革者偏执于方案之完美，在推行改革时拒绝倾听纠偏反馈（拗相公）
  → 将温和理性异议者污名化并进行行政清洗（立党人碑）
  → 组织内正直专业官吏被肃清，升迁通道只剩唯唯诺诺的谄媚小人（捧、恐、送齐备）
  → 投机帮凶为了向高层邀功，在基层执行时层层物理加码、敲骨吸髓
  → 政策严重扭曲，社会/组织底层信任大面积塌方，法度坏死
  → 系统在危机降临时轰然解体。
- **Conditions**: 组织纵向集权度极高，缺乏独立的异议保护与纠偏反馈通道。
- **Provenance**: `[001:L7053]`, `[015:L8528]`, `[013:L124]`

```
[偏执改革方案] ──> [肃清温和异议者] ──> [起用投机顺从者]
      ^                                           │
      │                                           v
[系统崩盘解体] <── [底层信任塌方坏死] <── [执行加码变形盘剥]
```

## 3. 领域核心张力与未解决矛盾 (Tensions)

### T001 本体级张力：反求诸己的道德宿命 vs. 环境对理性的物理剥夺
- **Contradiction**:
  心学与活法（[003], [016]）主张“心即理，万理皆备于我”，遭遇挫折必须绝对“反求诸己”，责任在我，排除得失；然而，社会心理学（[017]）通过线段从众实验和斯坦福监狱实验证实，极其强大的“社会环境压力与信息封闭控制”能在几小时内对个体的自由理智进行物理剥夺，迫使其盲从作恶。
- **Tension**: 这一张力展示了“个体的道德能动性上限”与“社会学环境的刚性塑造力”之间的终极搏杀。系统未给出“当环境压力达到多少物理分值时，个体心学抵抗会彻底脑死亡”的量化判定。

### T002 策略级张力：无条件敬天爱人利他 vs. 冷酷控制的情感隔离御下
- **Contradiction**:
  稻盛经营哲学（[016]）将“思利他、积善行、敬天爱人”作为事业圆满的终极核能，要求在利益分配时大比例让渡给客户和员工；而整人秘笈与权谋书（[019], [008], [013]）则字字泣血地警示，人性的贪婪具有无休止的扩张性，管理者与下属共事必须“不知底细、严立礼仪、恃刑立威、隐藏意图”，一旦表现得越界亲密或温情大度，会被下属视为软弱并直接进行反向操纵。
- **Tension**: 这是商业生态治理中“构建无私共同体”与“防范人性贪婪反噬”之间的永恒策略拉锯。

### T003 边界级张力：法家铁血强力国家动员 vs. 反忽悠事实自主权防线
- **Contradiction**:
  《商君书》（[002]）论证了国家求生的终极算法是“弱民、 farming-war、集权”，通过极端的刑罚和单一化评价将百姓驯化为耕战工具；而《忽悠原理》（[011]）则以生命攸关的警示，教导个体如何使用“物理底单质证、中立四标准”去击碎强权话语权的灌输，逃离信息污染与思维控制，维持心智的自主与自由。
- **Tension**: 这反映了“国家机器为求取物理生存的极限集权动员”与“个体为了理智存续而发起的反控制博弈”之间的终极政治学张力。
