## 1. 核心问题 Core Problem Space

《商君书》致力于解决的核心问题是：在战国兼并的剧烈竞争环境下，国家如何排除其他社会资源的干扰，将举国之力凝聚于“农业生产”与“对外战争”两个单一出口，从而在零和博弈中战胜强敌并称王天下。

它所关注的不是纯粹的道德教化或长治久安，而是：
1. 利益通道的绝对垄断：如何确保官爵和名利只能通过农战取得；
2. 弱民与强国的张力：如何通过压制私欲、杜绝智虑、限制游商学士来使民众驯服，并将其力量彻底工具化；
3. 法制的高效推行与权威：如何依靠严刑峻法，做到“以刑去刑”；
4. 历史发展与变法的动态适应性：如何论证“不法古，不修今”的变法必然性。

## 2. 核心论证结构 Central Thesis Architecture

《商君书》的逻辑链条可以重建为：
兼并竞争的社会形势变化
→ 治理手段必须随形势而变（不法古，不修今）
→ 国家强盛的核心动力在于农业（粮食保障）与战争（军事扩张）
→ 排除民众追求“诗书辩慧”、“商贾技艺”等逃避农战的通道（壹务）
→ 垄断官爵和名利的赏赐入口，使其仅能通过农战获得（利出一孔）
→ 建立极其严苛的刑罚体系，加重轻罪惩罚以消除犯罪与异己（以刑去刑）
→ 维持民众朴实、无智且贫穷的状态，使其必须依附国家（弱民）
→ 实现国家力量的高度凝聚与绝对指挥（国力抟）
→ 战胜敌国并称王天下。

## 3. 世界模型 World Model

### 3.1 明确或强重建的基本设定
- 趋利避害是人的天然本能。百姓畏惧严刑而向往官爵名利，统治者应当利用而非消灭这一本能（Evidence: lines 778, 1210）。
- 社会资源和思想多样性是国家凝聚力毒药。若儒家、游侠、商人、手工业者等能通过农战以外的方式获得财富或声誉，百姓就会逃避艰苦的农战，国家就会衰弱（Evidence: lines 805-809, 891-902）。
- 国家的权力和百姓的力量呈现零和博弈。民强则轻视政令，民弱则顺从法令。因此，要想国家强大，必须削弱民间的能动性与多余财富（Evidence: lines 1080-1082）。
- 历史是不断变化和演进的，没有永恒不变的制度。治理国家必须依据时代特性设定法度，不可盲目法古（Evidence: lines 55, 1847-1861）。
- 法律的威严在于其绝对的不折不扣执行和刑罚的严酷，而非仁义道德（Evidence: lines 65, 776）。

### 3.2 不是本书充分证明的设定
- “弱民”必然带来“强国”的长期可持续性。书中只描绘了秦变法在兼并战争时期的效能，并未证明该模型在和平与繁荣时期的内部稳定性。
- 排斥一切文化（诗书、礼乐）和智力探索（知虑）是文明演进的最佳方向。这一设定纯属强国御民的战略功利推导。
