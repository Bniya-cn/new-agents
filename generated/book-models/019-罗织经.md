## 1. 核心问题 Core Problem Space

《罗织经》所探讨的根本问题是：在缺乏监督、高度中心化的君权专制环境中，野心家（酷吏、阴谋者）如何通过“无中生有地织造罪名（罗织）”和“制造对死亡的极端恐惧”，彻底瓦解政治对手和下属的防线；以及君主/上位者如何利用酷吏清除功臣以控权，并在事后将酷吏作为平息民愤的祭品，实现权力的绝对集中与稳定。

它深入解构了：
1. 罪名的制造技术：如何将无辜者的正常行为构陷为君主最敏感的“谋反”之罪，以斩断其辩解空间；
2. 恐惧操纵与审讯学：如何通过残酷的肉体刑罚与心理施压，摧毁受审者的心智，迫使其承认虚假罪状并攀诬同伙；
3. 御下与控权的权术：如何通过“不知根底、恃刑立威、利益诱引与随时准备抛弃”来保持对部属的控制；
4. 酷吏的工具性宿命：酷吏如何在为君主充当“黑手”的同时，必然沦为君主在政治博弈后期的替罪羊。

## 2. 核心论证结构 Central Thesis Architecture

本书的整人与权力维系逻辑可以重建为：
君权专制下上位者最敏感的核心死穴是“失去权力”与“部属背叛”
→ 酷吏为了自保和上位，主动投其所好
→ 专门给人冠以“谋反不忠”的罪名，直击君主痛点（C002）

→ 当政治清洗结束、民怨沸腾或酷吏威胁到皇权时

→ 皇权复归，系统完成循环。

## 3. World Model 世界模型

### 3.1 明确或强重建的基本设定
- 权力博弈是绝对零和且缺乏道德底线的。所谓的“忠诚”在绝对利益与生存恐惧面前是极其易碎的假象（Evidence: lines 1242, 1356）。
- 上位者多疑，下属多惧。这种权力的不对称决定了告密和谗言拥有天然的生存空间，因为君主宁可信其有（Evidence: lines 1234-1242, 2000）。
- 罪名不需要事实，只需要“符合君主的心理需求”。一旦被指控为谋反，辩解是无效的，唯一的出路是比酷吏更早揣摩君主的心思（Evidence: lines 169, 1356）。
- 威严的维系依赖于刚性的暴力（刑罚）。任何对下属的小过失纵容和大度，都会被部属视为软弱，导致控制力的丧失（Evidence: lines 2053）。
- 酷吏是不可再生的权力“耗材”。他们因为帮君主做脏活而得势，但也因为脏活败露、民怨沸腾而注定成为弃子（Evidence: lines 1, 168-170, 721）。

### 3.2 不是本书充分证明的设定
- 所有被指控的人都一定会屈招。狄仁杰等极少数顶级政治家通过主动“认罪”以规避即时刑讯折磨，并暗中向武则天传送密信，证明了高智商对抗在特定政治夹缝中依然有生还率（Evidence: lines 169）。

## 5. 主要判断 Major Claims

### CL001 构陷政敌的第一秘诀在于“将其正常举动强行绑定至谋反”
- Type: strategic / causal
- Status: source
- Mechanism: 无论政敌的品德多么无懈可击，都必须寻找或制造蛛丝马迹，将其正常的人员往来、购买武器或闭门谢客，解释为“密谋造反、对君不忠”。因为只有谋反罪能让皇帝产生极度恐惧，从而绕过正常的司法审计。
- Assumptions: 上位者对叛乱的警惕和恐惧，远超其对司法公正的追求。
- Boundary: 在有强力分权治理、独立司法终审和新闻舆论公开的制度下，无证据的“谋反”指控无法通过立案审查。
- Evidence: lines 52, 1242, 1356

### CL002 审讯的关键在于“彻底剥离同情，依靠肉体极限制造认罪”
- Type: behavioral / causal
- Status: source
- Mechanism: 审讯绝不是讲道理的过程。必须发明让人生不如死的残酷刑具（如周兴的瓮），通过极限的生理痛苦制造死亡恐惧，受审者为了获得一时的痛苦缓解，必定会答应酷吏的任何认罪要求。
- Assumptions: 人的生理痛觉极限是绝对的，绝大多数人的意志无法对抗物理生理摧毁。
- Boundary: 拥有法治保障、禁止刑讯逼供且有律师在场的现代司法审讯中，此类口供被视为无效证据。
- Evidence: lines 417, 423, 703

### CL003 威严立于礼仪区隔，恃于严刑，丧于宽容纵任
- Type: social / causal
- Status: source
- Mechanism: 统治者与被统治者必须通过森严的礼仪保持距离；权威必须通过坚定的惩罚（恃以刑）进行维持；一旦对部属的僭越或过失表示宽容和放任，会被解读为“软弱”，导致权力迅速流失。
- Assumptions: 人性具有得寸进尺的扩张本能，权力只能通过力量阻吓来维持平衡。
- Boundary: 在高度依赖创意协作的自发性敏捷团队中，过度恃刑会导致告密横行、创新彻底归零。
- Evidence: lines 2053

### CL004 御下必须保持信息彻底不对称（不示底细）
- Type: strategic / defensive
- Status: source
- Mechanism: 下属一旦知道了老板的真实喜恶、底细或软肋，就会针对性地进行迎合、谄媚或要挟，从而反向操纵上司。因此，御下第一法则是“隐藏意图，保持距离”。
- Assumptions: 下属与上司之间存在天然的利益博弈，下属会利用一切漏洞谋私。
- Boundary: 正常的日常情感交流在小团队中能增加凝聚力，过度防御会导致团队极度冰冷。
- Evidence: lines 307, 1950

## 8. Judgment Heuristics 判断规则

### H001 遭受构陷指控时，绝不进行无意义的常规“喊冤自辩”，主动“认罪”并直接向最高决策者提交密信破局
- Use when: 职场或政治斗争中被对手罗织罪名、面临单向的信息封锁与酷吏审讯。
- Diagnostic question: 审讯者是否是带着“定罪任务”来的？我顺从自辩是否能通过其偏见程序？
- Reasoning: 酷吏审讯最忌不忍，辩解只会招致更残酷的折磨；狄仁杰先认罪保命、再递信给武则天，是唯一解。
- Action tendency: 在初审时顺从认罪以终止肉体和即时伤害，保留体力；暗中通过非正式渠道（如信人）将真实的冤情与对方跨过酷吏，直接递交到最高裁判者（皇帝）手中。
- Boundary conditions: 必须确信最高裁判者对你仍存有基本的利用价值或一丝香火之情。
- Status: source-explicit
- Evidence: lines 169

### H002 御下与下属交往时，恪守“不知底细、严立礼仪、保持距离”的御下三红线
- Use when: 晋升为部门高管、掌管核心项目，或管理具有极强进取心野心的部属。

- Reasoning: 威信丧失于放任；下属知道根底，便能反向操纵上司。

- Boundary conditions: 对共事十年的极少数已通过极限忠诚核验的核心合伙人，可适当放宽情感隔离，但依然保持账目和权力的清晰。
- Status: source-explicit
- Evidence: lines 307, 1950, 2053

### H003 绝不帮违法的“最高决策者”去干伤天害理的脏活，严守“工具人”的防反噬边界
- Use when: 老板要求你去执行违法的财务做账、构陷其他副总裁，或者干脏活。

## 12. 内部张力与未解决矛盾

### P001 遭遇定向清洗时的“狄仁杰保命破局原则”（认罪求生）

- Mechanism: 构陷程序是零同情的偏见闭环，自辩无效；只有保全身体并打通跨级沟通，才能打破信息封锁。
- Scope: 职场恶意清洗、不公平审计、恶意诉讼。
- Conditions: 存在一个有决策权且不受构陷者完全控制的最高裁判者。
- Failure conditions: 如果最高决策裁判者本身就是直接下达肉体消灭指令的终极元凶，认罪只会加速死亡。
- Status: source-explicit
- Evidence: lines 169

### P002 核心管理的“情感隔离御下原则”（御下隔离）
- Principle: 管理者在掌管高敏感项目和团队时，绝不在非正式场合向部属透露个人的情感好恶、经济底细或私人弱点；必须通过标准的职业流程和礼仪保持刚性距离，防止信息反向操纵。
- Mechanism: 隐藏意图能消除被迎合与要挟的软肋，礼仪区隔是维持规则阻吓力的心理防线。
- Scope: 高管管理、核心研发团队治理、风险合规控制。
- Conditions: 团队内部存在极强的利益竞争与上升野心。
- Failure conditions: 在需要高度信任、共享愿景的早期合伙人创业研发中，过度的情感隔离会扼杀凝聚力。
- Status: source-explicit
- Evidence: lines 307, 1950, 2053

### P003 帮凶出局的“替罪羊防线原则”（拒绝脏活）
- Principle: 在任何组织中，行动者一律坚决拒绝帮决策者去干越过道德与合规红线的违规清算（脏活）；一旦发现被推向风口浪尖，必须立即以病假、转岗或离职进行物理切割，绝不存侥幸。
- Mechanism: 违规行为积累的社会怨恨必然在收尾期由决策者通过“杀帮凶平民愤”来闭环，没有任何帮凶能安全着陆。
- Scope: 财务做假拒绝、非法裁员执行规避、灰色合规风险防范。
- Conditions: 决策者暗示或明示你执行违规操作。
- Failure conditions: 无。
- Status: strong-reconstruction
- Evidence: lines 1, 168-170, 721
